# JobConnect — College Job Portal Project

A responsive job portal demonstration made with HTML, CSS and vanilla JavaScript.

## Features
- Responsive homepage and job cards
- Search by job title, company, keyword and location
- Filter by category, job type and work mode
- Sort by salary
- Save/unsave jobs in the current browser
- Demo application form
- Add sample job form
- Uses browser `localStorage` for demo data

## Run locally
1. Extract `JobConnect_College_Project.zip`.
2. Open the folder.
3. Double-click `index.html` to open it in your browser.
4. For a better development experience, open the folder in Visual Studio Code and use the Live Server extension.

## Publish free using GitHub Pages
1. Sign in at https://github.com/ and create a **public** repository named `JobPortal`.
2. Upload `index.html`, `style.css`, and `script.js` (README.md is optional).
3. Open repository **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/(root)`, then save.
6. Wait for the deployment to finish. Open the URL shown in the Pages settings, usually `https://YOUR-USERNAME.github.io/JobPortal/`.

## Important project limitations
This is a front-end demo, not a production recruitment platform:
- Jobs and applications are stored in each browser's localStorage, so they are not shared between users or devices.
- There is no secure login, server-side admin, email sending, or central database.
- Do not enter real sensitive personal information.
- To make a production-style project, add a backend/database such as PHP + MySQL or Supabase, with secure authentication and access policies.
